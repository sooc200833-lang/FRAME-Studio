# 3D 배경 카메라 애니메이션 + 선 다시 그리기 (boil)

작성: 2026-11-28 · 상태: 1차 구현 완료 (`feature/3d-camera-animation`, v1.19)

## 목표

3D로 만든 배경을 **움직이는 손그림 배경**으로 그리기 타임라인에 넣는다.

1. 카메라가 움직이는 장면(패닝, 줌인, 돌아보기)을 3D 스튜디오에서 키프레임으로 만든다.
2. 카메라가 멈춰 있어도 선이 초당 몇 장씩 **손으로 다시 그린 것처럼** 바뀐다 (boil).
3. 결과를 그리기 화면에 **배경 레이어 하나 + 클립 여러 개**로 보낸다. 같은 그림이 이어지는 구간은 하나의 클립(길게 유지)으로 합친다.

## 사용 흐름

3D 스튜디오 → **카메라 애니메이션** 패널

- **길이**(프레임)와 **초당 프레임**(8 / 12 / 24)을 정한다.
- 아래 막대(스크러버)로 프레임을 고르고, 카메라를 맞춘 뒤 **키 저장**을 누른다. 그 프레임의 카메라(위치, 바라보는 점, 화각, 확대)가 키가 된다.
  - 키 사이 움직임: **부드럽게** 또는 **일정하게**.
  - **키 삭제**는 현재 프레임의 키를 지운다.
- **선 다시 그리기**: 끄기 / 초당 12 · 8 · 6 · 4장. 같은 선이 그 리듬으로 조금씩 다르게 그려진다 (선 스타일이 깔끔이면 바뀌지 않는다).
- **▶ 재생**으로 미리 본다.
- **그리기로 보내기**: 키가 2개 이상이거나 선 다시 그리기가 켜져 있으면 "애니메이션으로 보내기"(기본 켜짐)가 적용된다.

그리기 화면

- 맨 아래에 새 배경 레이어가 생기고, 그 트랙에 프레임들이 클립으로 들어간다.
- 프로젝트의 초당 프레임이 다르면 시간이 같도록 클립 길이를 맞춘다.

## 완료 기준

- 키 0개·boil 끔이면 지금과 똑같이 한 장만 보낸다.
- 키 2개, 24프레임 → 24개(또는 그보다 적은, 같은 그림이 합쳐진) 클립, 총 길이 24틱 (12fps 프로젝트 기준).
- 카메라 고정 + boil 초당 4장 + 12fps → 클립마다 3틱 유지.
- 저장한 장면(JSON)과 "3D로 다시 편집"에 카메라 키와 설정이 함께 간다. 예전 장면은 애니메이션 없이 열린다.
- 화면 미리보기와 보낸 프레임이 같은 그림이다 (같은 카메라 계산, 같은 boil 단계).
- 보간·boil 단계·프레임 합치기·fps 변환은 순수 함수로 테스트한다.

## 이번에 하지 않는 것

- 애니메이션 배경 레이어를 "레이어 업데이트"로 통째 교체하기: 타임라인 편집은 아직 되돌리기가 안 되므로, 애니메이션은 항상 **새 레이어**로 보낸다.
- 움직이는 투시선 레이어 (애니메이션일 때 투시선은 보내지 않는다).
- 오브젝트 움직임 키프레임, 카메라 경로 곡선 편집.
- 많은 프레임의 메모리: 1200×900 PNG 프레임이 클립마다 data URL로 저장된다. 길이는 최대 240프레임으로 제한한다.
